本地服务在线
执行前检查新邮箱不能已绑定其他 OpenAI 账号；账号需可使用 Settings → Account 自助换绑。单账号最多 24 小时 2 次、生命周期 20 次。
双重自动轮换每个账号先从“换绑代理”池随机选择一条执行纯协议流程；代理网络失败时立即标记并随机换下一条，不消耗替换邮箱。收不到新邮箱验证码、取码 API 超时或新邮箱已被占用时，才隔离该邮箱并为同一原账号换下一个邮箱。
纯协议模式换绑核心使用 chatgpt-rebind-standalone：默认全程不打开浏览器；勾选“完成后开 Roxy”时，纯协议换绑成功后才额外选择另一条代理，新建 Roxy 窗口并登录替换邮箱。
01

导入原邮箱账号

只进入原账号

这个入口导入的内容全部属于换绑前的原邮箱。 同时支持“邮箱+取码 URL”和“邮箱+密码+2FA”，不会再进入替换邮箱号池。

02

导入替换邮箱

邮箱 · API

这个入口只导入换绑后要使用的新邮箱。 邮箱+URL 会加入“替换邮箱”号池，和原邮箱入口完全分开。

03

导入换绑代理

每行一条

每个账号随机取一条执行纯协议换绑；带认证但未写协议的格式默认按 SOCKS5 导入。勾选完成后开 Roxy 时，成功后会再选另一条代理打开窗口。

04

一对一配对

默认使用纯协议完成原邮箱登录、换绑、新邮箱重登和 AT 获取，不启动 Roxy。需要保留浏览器登录态时勾选“完成后开 Roxy”，系统会在换绑完成后额外选择第二条代理打开窗口。

原邮箱账号状态一对一替换邮箱操作
05

完成结果

按原邮箱导入类型轮转：密码账号复制“原邮箱----换绑后邮箱----密码----2FA----AT”；URL 账号复制“原邮箱----换绑后邮箱----替换邮箱URL----AT”。可选择结果记录后批量清理。
